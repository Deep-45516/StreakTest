# Streak Snapchat Automation V5 - Krisha

This is a patch for the existing StreakTest Codespaces project. It intentionally does NOT include Gradle files or local.properties so the working build configuration is not overwritten.

Flow:
Snap composer -> Send To -> wait -> tap 💯 -> wait -> find Krisha/krisharkive2 -> tap Krisha -> finish.

No final Send tap is performed because on the user's phone selecting Krisha sends the Snap immediately.
